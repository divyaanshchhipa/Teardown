# Vendored font

| File | Source | License |
|---|---|---|
| `inter-var.woff2` | https://cdn.jsdelivr.net/fontsource/fonts/inter:vf@latest/latin-wght-normal.woff2 | SIL OFL 1.1 |
| `inter-var-italic.woff2` | https://cdn.jsdelivr.net/fontsource/fonts/inter:vf@latest/latin-wght-italic.woff2 | SIL OFL 1.1 |

Inter, by Rasmus Andersson (rsms.me/inter). Variable weight axis (100-900), Latin
subset, packaged by the Fontsource project. Self-hosted rather than loaded from
a CDN so the site keeps working from `file://` and offline, matching the
`js/vendor/` pattern used for three.js. ~100KB total for both files, which is
why the variable-weight build was chosen over static per-weight files.
